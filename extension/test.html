Welcome to LexiFlow

LexiFlow is a revolutionary browser extension that reads documentation line by line.

This is the second sentence. It will be highlighted when the extension reads it.

The extension uses browser text-to-speech technology. This means no API keys are required.

You can control the reading speed from 0.5x to 2x. This helps you read at your own pace.

Key Features

LexiFlow works on any webpage. It extracts the main content automatically.

The highlighting follows along as the text is read. This creates a Spotify-like experience.

You can pause and resume at any time. The extension remembers your position.

Navigation controls let you skip forward or backward. This is useful for reviewing content.

How It Works

The extension injects a content script into every page. This script extracts readable text.

Sentences are identified using pattern matching. They are filtered for quality.

The browser's speech synthesis API provides the voice. Multiple voices are available.

As each sentence is spoken, it gets highlighted on the page. The page auto-scrolls to keep it visible.

Benefits

LexiFlow makes documentation more accessible. You can listen while doing other tasks.

It helps with comprehension by following along. Visual and audio learning work together.

The synchronized highlighting keeps you focused. You always know where you are in the document.

Best of all, it works offline with no setup required. Just install and start reading!
